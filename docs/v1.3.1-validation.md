# v1.3.1 操作パネルと残り時間の検証

今回の変更は操作パネルのサイズ・位置と、残り時間の表示設定のみです。ゲージ形状・タイマー・音声エンジンはv1.3.0を維持しています。

## 操作パネル

Electronの`screen.workArea`はDIP単位です。表示倍率を再度掛けず、作業領域内で初期幅を最大1180 DIPに決めます。CSSは3列／2列／1列に切り替え、レンダラーから通知された内容の実測高さにウィンドウ枠の高さを加えて調整します。作業領域を超える高さにはせず、必要な場合だけ縦スクロールします。

手動サイズと位置は`window-state.json`に保存します。自動サイズと手動サイズを区別し、自動サイズだった場合は次回も内容・作業領域に合わせて再計算します。手動変更は復元を優先し、画面外になる位置と大きさだけ補正します。投影先の変更時は操作パネルを別のディスプレイへ移動し、既存の手動サイズを保ちます。

ローカルの実Electronでは1364×1024 DIPの作業領域に対し、1180×757 DIP（内容1180×729）で全設定項目が収まりました。これはLinux試験環境の値です。Windowsの枠・フォントによって必要な高さは変わるため、Windows CIでも実アプリを起動して再計測します。

## 残り時間とプレビュー

文字サイズ12〜120px（初期28）、文字色（初期白）、9位置（初期右上）、文字透明度0〜100%（初期100）、余白0〜100px（初期24）をWeb／PiP／Electronで共通化しています。小さい表示領域では文字を縮小し、位置を画面内に補正します。影を維持し、文字透明度0%は終了点滅中も透明のままです。

プレビューは投影先ディスプレイのDIP寸法を縮小したものです。共通の配置関数と同じフォント・色・透明度を使用します。設定変更はタイマーを停止させません。文字OFFでもゲージは維持します。v1.3.0の音声設定ファイルはそのまま読み込み、新しい項目は初期値で補完します。Webの既存の文字サイズ・四隅位置も引き継ぎます。

検証内容：

- 単体126件：12解像度・倍率条件の作業領域、負座標／切断後の補正、9位置・文字サイズ・余白、入力範囲、既存タイマー／音声／ゲージ等。
- 実Electron243条件：サイズ3種×位置9種×透明度3種×余白3種。実オーバーレイとプレビューの座標・色・透明度を比較。設定中も進行、ゲージ透明度35%からの独立、文字OFFを検査。
- 実Electronの再起動：手動サイズ・位置と文字設定の復元、画面外の保存座標の補正、自動サイズだった場合の内容に応じた再計算、旧設定読み込み。
- 実ブラウザ：12レイアウト＋Web243表示条件、保存復元、文字OFF・ゲージ独立。PiPで9位置、色・サイズ・余白・透明度、閉じて再表示等を検査。
- v1.3.0回帰：四隅240条件、音声60波形、6種類の試聴、START／PAUSE／RESUME／RESET、独立した音声ウィンドウ、点滅、OSのクリック・スクロール透過。
- 配布物：実ポータブルexeとSetupインストール後の実アプリを起動。`app.asar`の主要14ファイルがソースと一致することをSHA-256で確認。

Windows CIと公開配布物の最終結果はPRおよびReleaseに記録します。CIの証跡は`desktop-evidence`／`browser-evidence`です。

## 未検証・制約

物理マルチモニター／プロジェクターの接続・切断、Windows設定画面での倍率変更、Zoom／PowerPointの実アプリ、人間による実スピーカー聴取は未検証です。倍率と切断のモデル検査・保存された画面外座標の復元試験とは区別してください。PiPはブラウザ／OSの位置・大きさ・透明度・最前面の制限を受け、任意アプリを囲む透明クリック透過枠を保証しません。
