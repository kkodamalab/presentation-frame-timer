OVERLAY GUIDE

Zoomの上に重ねるには

通常のWebブラウザでは、他アプリの上に透明なフレームを固定できません。FULLSCREENもブラウザ内の表示です。

Windowsで自分だけに表示 → Electron

透明・最前面・クリック透過の専用ウィンドウが最適です。Windows版は透明・最前面・クリック透過で表示します。操作は別ウィンドウで行います。Windows版ダウンロード（Release） ↗

配信・共有映像に合成 → OBS

画面キャプチャの上にBrowser Sourceを配置します。下のURLは背景透過のゲージのみを表示し、読み込み時に開始します。秒数はURLで指定できます。OBSの再読み込みでタイマーはリセットされます。

OBS用表示を開く ↗

ブラウザの設定・操作とは同期しません。OBSの「表示されていないときにソースをシャットダウン」「シーンがアクティブになったときにブラウザを更新」はOFFにしてください。

インストール不要 → WEB OVERLAY（実験版）

上部のWEB OVERLAYボタンからPiPを開きます。COMPACT / FRAMEを選び、元タブから操作できます。FRAMEはPiP自身の外周であり、Zoom画面全体の透明クリック透過フレームにはなりません。
